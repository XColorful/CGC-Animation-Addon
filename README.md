# CGC Animation Addon

This mod is a player animation addon for [Custom Gun Continued](https://github.com/XColorful/Custom-Gun-Continued).
- Provides compatibility support for [PlayerAnimator](https://github.com/KosmX/minecraftPlayerAnimator)

---

`This mod needs to be installed on the client.`
